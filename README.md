## Featured projects

### [EcoFire API](https://github.com/danieldiaz98/EcoFireApi)

REST API that calculates the **forest fire risk index in the Canary Islands**. It combines real-time weather data from Open-Meteo with a rule engine that evaluates temperature, humidity and wind, including the critical **30-30-30 rule**. Built with FastAPI, Pydantic v2 and HTTPX, with a tested domain layer.

`Python` · `FastAPI` · `Pydantic` · `Open-Meteo` · `Pytest`

### [SurfTFG](https://github.com/danieldiaz98/surftfg)

Web and Android application for the surfing community: discover spots, check weather conditions, share photos, follow other users and trade gear in a marketplace. Built with **React + Vite** and packaged for Android with **Capacitor**, using **Supabase** for auth and data.

`React` · `Vite` · `Capacitor` · `Supabase` · `Google Maps` · `Stormglass`

### [DeliYou](https://github.com/danieldiaz98/DeliYou)

Android food-ordering app built in **Kotlin**: browse restaurants, explore menus, manage a shopping cart and save favourites. Authentication and cloud data are handled with **Firebase**, while the cart and favourites are persisted locally with **SQLite**.

`Kotlin` · `Android` · `Firebase Auth` · `Firestore` · `SQLite` · `Picasso`
